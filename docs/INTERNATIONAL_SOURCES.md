# 国际条约资料与导入

资料来自清单登记的 WIPO、WTO 官方链接。详情页只用于确认来源和版本，入库正文来自其链接的原始 PDF。清单保存来源入口、正文下载入口、获取时间、语言、文件哈希、物理页数及解析范围；原文件保存在被 Git 忽略的 `data/raw/treaties/`。

## 获取与部署

完成 Python 环境与 `.env` 配置后：

```bash
# 恢复清单中已核对的官方PDF；不调用模型
.venv/bin/python scripts/download_treaties.py

# 校验哈希、页数、正文条号，生成可检索片段
.venv/bin/python -m patent_agent.cli parse

# 向已配置的向量服务发送新增片段，产生API用量
.venv/bin/python -m patent_agent.cli index

.venv/bin/python scripts/serve.py
```

下载器遇到官方文件哈希变化时停止，不自动接纳新版本。需要核对新文件的版本、目录、页码、删除条款、附件及警告后再更新清单。提取缓存文件名含原始PDF哈希。

索引在完整性检查后原子激活；构建失败可重试。向量配置和片段ID一致时复用历史快照向量，避免重复发送已有原文。旧会话保持原快照，新增资料生效后应点击“开始新会话”。历史快照及其PDF需要保留，才能继续查阅旧引用。

## 解析和引用

正文按条、规则或行政规程编号分块，支持 `bis`、`ter` 等增补编号。目录排除范围来自逐文件核对；对整段标记“已删除”的条号范围分别提供定位，但原文不改写。附件和费用表按物理页保留，使用 `appendix:page:70` 等定位。

宽范围语义检索按相关度排序，不按清单顺序给每份文件强行分配结果。明确指定少量来源时保留跨文件覆盖。精确查找、语义检索和引用均绑定同一知识库快照，界面可打开官方来源和本地PDF对应物理页。

## 版本与覆盖边界

- 巴黎公约和斯特拉斯堡协定：官方英文条目列1979年9月28日修正，所载中文PDF列1979年10月2日。两种信息均保留并告警，不擅自改写原文。
- PCT行政规程：所载文件仅含附件A、F的说明页，未附其全文。附件B、C、D、E、G、H按页保留；表格、序列表、代码格式和图示需对照原PDF。
- 海牙议定书：原文件脚注明确“尚未生效”，作为带状态提示的资料保留，不视为已生效的一般规则。
- TRIPS：2005年修正议定书于2017年1月23日生效；各成员是否受修正约束取决于其接受情况，不能将此日期直接视为每一成员的适用日期。
- 官方来源不等于已确认对具体国家、时期或案件适用。系统未独立核验全部缔约状态、保留、声明及后续修订；各文件也不具有统一版本日期。
- 英文原文可以用中文解释，但直接引文保留英文，中文解释不标注为官方译文。

多条规定共用一页时，页底脚注可能随该页末条的文本收录；涉及脚注的判断应结合原PDF整页核对，不能只看单个条文片段。
